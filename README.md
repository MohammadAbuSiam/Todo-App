# Todo App

A Flutter application for organizing and managing daily tasks.

## Features

-   Task management interface built with Flutter.
-   Firebase integration using Firebase Core and Cloud Firestore.
-   Firebase Authentication support.
-   Local preferences using Shared Preferences.
-   State management with GetX.
-   Google Fonts for typography.

## Built With

-   [Flutter](https://flutter.dev/)
-   [Dart](https://dart.dev/)
-   [Firebase](https://firebase.google.com/)
-   Cloud Firestore
-   Firebase Authentication
-   GetX
-   Shared Preferences
-   Google Fonts

## Getting Started

### Prerequisites

Make sure you have installed:

-   Flutter SDK
-   Dart SDK (included with Flutter)
-   Android Studio, VS Code, or another Flutter-compatible IDE

### Installation

1.  Clone the repository:

    ``` bash
    git clone https://github.com/MohammadAbuSiam/Todo-App.git
    ```

2.  Open the project directory:

    ``` bash
    cd Todo-App
    ```

3.  Install dependencies:

    ``` bash
    flutter pub get
    ```

4.  Configure Firebase for your development platform if it is not
    already configured.

5.  Run the application:

    ``` bash
    flutter run
    ```

## Project Structure

-   `lib/` --- Application source code.
-   `test/` --- Tests.
-   `android/` --- Android platform files.
